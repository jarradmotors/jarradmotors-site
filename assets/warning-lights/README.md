Source pinned to https://github.com/Templarian/MaterialDesign/tree/2424e748e0cc63ab7b9c095a099b9fe239b737c0/svg . Geometry is unchanged; colours, titles and unneeded root metadata were adjusted. No icon font, JavaScript or runtime CDN is required.

`dpf.svg` is an original generic filter/dots/exhaust pictogram. Manufacturer images were used as recognition references, not copied into the repository. Visual forms were cross-checked against [Ford Australia’s indicator examples](https://www.ford.com.au/owners/vehicle-support/indicator-icons/) and [Ford’s dashboard guide](https://www.ford.co.uk/support/how-tos/more-vehicle-topics/lights-and-bulbs/what-do-the-lights-on-my-dashboard-mean). These illustrations are generic examples, not manufacturer-specific or ISO-certified artwork.

The flashing-engine card deliberately uses the same engine outline as the steady light. A static “Flashing” label identifies the behaviour; no decorative rays or flashing animation are added. The combined ABS/traction card shows both distinct symbols. Red charging/SRS and amber service examples replace the earlier arbitrary colours; actual colours and symbols vary by vehicle.
